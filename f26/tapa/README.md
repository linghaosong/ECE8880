# TAPA 0.1.20250815

This Linux x86-64 package was built from
[UCLA-VAST/tapa commit `9a572fc`](https://github.com/UCLA-VAST/tapa/tree/9a572fc40c74b533aaf29a728a1697cc2248de28)
for Xilinx Vivado/Vitis 2024.2.

In an NRP Coder terminal, run:

```bash
cd f26/tapa
./install-tapa.sh
exec "$SHELL" -l
```

The installer verifies the package checksum and version, installs TAPA in
`~/.rapidstream-tapa`, and adds it to zsh and bash.
